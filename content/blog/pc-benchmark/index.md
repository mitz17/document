## PCの背景とOSの使い分け

このPCはもともとUbuntu専用の開発・ローカルAI実験用として組んだが、GeForce RTX 4070 SUPERを活かしてゲームにも使いたくなり、Windows 11 Proを追加してデュアルブート化した。Proを選んだのは、標準のリモートデスクトップでホスト側になれる点が扱いやすかったためだ。

| OS | 主な用途 |
|---|---|
| Ubuntu | 開発、ローカルAI、CUDA、技術検証 |
| Windows 11 Pro | ゲーム、Windows向けベンチマーク |

本記事の測定は、特記がない限りWindows 11 Pro上で実施している。

## 結論

Ryzen 5 7600とRTX 4070 SUPERの組み合わせは、フルHD環境でPalworldを最高設定にしても、通常時はおおむね60 FPSでプレイできた。一方、負荷の高い場面では42 FPSまで低下した。

主な検証結果は以下のとおりだ。

- Palworld：最高設定で通常時約60 FPS、低下時42 FPS（1回のみの参考測定）。体感では時々軽いカクつきがあるものの、プレイには全く問題なし
- RTX 4070 SUPERはフルHDには過剰か：Palworldの実測ログでは、GPUコア使用率は最大68%にとどまり、CPU使用率が先に91.3%まで達していた。GPUには余力があり、CPUが先にボトルネックになっていたと考えられる

## 検証方法

温度・使用率の記録には[HWiNFO64](https://www.hwinfo.com/download/)を使用した。公式サイトから無料でダウンロードでき、インストーラー版とポータブル版（ZIP、インストール不要）が選べる。今回はポータブル版（`hwi64_850`）を使用した。

再現性を高めるため、実際の測定では次のように条件をそろえた。

- 起動していたのはベンチマークソフト本体とHWiNFO64のみで、それ以外のアプリケーションはすべて終了した
- 測定中にWindows Updateが走らないよう、測定前に更新状況を確認した
- グラフィック設定は、各ベンチマーク・ゲームで測定前後に変更せず固定した
- 各ベンチマークは1回のみ実施した
- 高負荷テストの間には5分のインターバルを設け、PCを冷却した
- 室温、CPU温度、GPU温度を記録した
- PalworldのFPSは、Steamの標準FPS表示機能を使用して確認した

### 測定環境

| 項目 | 内容 |
|---|---|
| 室温 | 25 ℃ |
| 温度計測ソフト | [HWiNFO64](https://www.hwinfo.com/download/)（`hwi64_850`） |
| ベンチマークソフトの保存先 | Cドライブ（M.2 NVMe SSD） |
| V-Sync | オフ |
| FPS上限 | なし（無制限） |

## 解像度について

使用しているモニターのネイティブ解像度は1920 × 1080、リフレッシュレートは120Hzだ。そのため、ゲームの主要な検証はすべてフルHDで実施する。

V-Syncはオフ、FPS上限もなしで測定しているため、理論上はモニターの120Hz近くまでフレームレートを出せる環境だ。

## 合成ベンチマーク

### Cinebench 2026

Cinebench 2026（バージョン2026.1.3）を使用し、Ryzen 5 7600のシングルコア性能とマルチコア性能、およびGPU性能を測定する。

| テスト | スコア | CPU最高温度 | GPU最高温度 |
|---|---:|---:|---:|
| CPU Single Core | 574 pts | - | - |
| CPU Multi Core | 3043 pts | 86.1 ℃ | - |
| GPU | 77647 pts | 83.6 ℃ | 64.6 ℃ |

Cinebenchはレンダリング性能を測る合成ベンチマークであり、ゲーム性能を直接示すものではない。

### 3DMark（Time Spy）

3DMarkは、国内外のPCレビューやゲーミングPC比較で広く使用されている定番ベンチマークだ。本記事では、追加購入なしで利用できる無料版の標準実行を使用する。カスタム実行は有料版の機能であるため、設定変更は行わず、標準設定の結果を記録する。

| 項目 | 結果 |
|---|---:|
| 総合スコア | 16554 |
| Graphics Score | 19739 |
| CPU Score | 8648 |
| GPU最高温度 | 82.9 ℃ |

## ゲーム性能

### Palworld

Palworldは、ゲーム全体を比較するための正式な検証ではなく、実際のプレイ中にどの程度のフレームレートになるかを確認する参考測定として扱う。測定は1回のみだ。

最高設定でプレイし、フィールド探索や戦闘を含む通常のプレイ中に、Steamの標準FPS表示機能でフレームレートを確認した。表示上では、通常時はおおむね60 FPSで動作し、負荷が高い場面では42 FPSまで低下した。

| 項目 | 結果 |
|---|---:|
| グラフィック設定 | 最高 |
| 測定回数 | 1回 |
| 通常時のFPS | 約60 FPS |
| 確認できた最低FPS | 42 FPS |
| レイド | 未検証 |

画面キャプチャでも42 FPSと表示されており、HWiNFOのログ（`pal.CSV`）も保存している。ただし、今回は固定ルート・同一条件で複数回測定した結果ではないため、平均FPSや1% Lowの厳密な比較値としてではなく、参考値として見るべきだ。

体感としては、場面によってたまに軽いカクつきを感じることはあるが、プレイの快適さを損なうほどではなく、通常プレイには全く問題ないレベルだ。

![Palworldを最高設定でプレイ中の画面。FPSカウンターは42 FPSを表示](palworld-42fps.jpg)

レイドはまだ試していない。敵やエフェクト、建築物などが集中するため、実際のレイドでは今回の最低値よりさらに低くなる可能性がある。

## 実測データから見えたこと

比較対象のGPUや複数タイトルでの検証はしていないため、「過剰かどうか」を一般論として断定することはできない。ただし、Palworld計測時に保存していたHWiNFOのログには、GPU使用率とCPU使用率の記録も残っていた。

| 項目 | 平均 | 最大 |
|---|---:|---:|
| GPUコア使用率 | 28.5% | 68.0% |
| CPU総使用率 | 28.7% | 91.3% |

GPUコア使用率は最大でも68%にとどまり、計測中を通じて余力を残していた。一方でCPU総使用率は91.3%まで達する場面があり、GPUより先にCPUが上限に近づいている。42 FPSまで落ち込んだ場面も、GPU性能の不足ではなくCPU側の負荷が主因だった可能性が高いと考えられる。

つまり、少なくともPalworldをこの設定でプレイする限り、RTX 4070 SUPERはボトルネックになっておらず、性能を持て余していたと言える。ただし1回のプレイセッションのみの記録であり、他のタイトルやレイドのような高負荷場面では傾向が変わる可能性がある。
