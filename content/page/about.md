## プロフィール

こんにちは、mitz17です。  
ハードウェアとソフトウェアの両方を触りながら、日常を少し便利にできるようなコツやツールを作って公開しています。

日常をハックするのが趣味のエンジニアで、できることは何でも自分の手で試してみたい DIY 気質です。

このブログは、自作ツール開発と業務自動化・効率化の実験ログを主軸にしています。

主に次のような内容を扱っています。

- Python を使った小さな自作ツール
- 業務や日常で役立つ自動化メモ
- ハードウェアやPCまわりの実験・構成記録
- 使っていて「なんか便利になりそう」と思ったものの実装ログ

読者としては、

- DIY が好きな人
- Python を少し触れる人
- 自作ツールや技術メモに興味がある人

を想定しています。

大きなサービスを作るというよりは、日々のちょっとした不便を減らすための小さな工夫やツールを積み上げていくのが好きです。  
何か便利になりそうなものを作ったら、その都度このブログで更新していきます。

## 実はハードウェア派

ソフトの自動化も大好きですが、実はハードウェアをいじっている時間のほうがワクワクします。  
電子工作やガジェットいじりをしていると、つい時間を忘れてしまいます。
